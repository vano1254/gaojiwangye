使用说明与实现要点

HOW IT WORKS

一、怎么用这个页面

  • 直接双击 D:\vscodehtml\index.html 用浏览器打开。
  • 顶部搜索框可按 标题 / 文件名 / 路径 / 知识点 模糊筛选。
  • 筛选按钮可按 课堂实践 / 可离线 / 需联网 / 工程模板 分类查看。
  • 点卡片标题或「打开页面」、点列表行任意位置，都会在新标签页打开对应网页。

二、标记含义

  • 课堂实践 本目录第 2~11 章的课堂作品，全部可离线打开。
  • 可离线打开 无任何外部资源，断网也能正常渲染。
  • 需联网 引用了在线字体或在线图片，断网时字体与图片会降级。
  • 需构建 前端工程（Vite / React）的入口骨架，双击只能看到空白页， 需先安装依赖并构建或启动开发服务器。

三、原生实现要点

  • 结构：语义化标签 header / section / article / nav / footer。
  • 样式：全部写在 <head> 内的 <style> 中， 用 CSS 自定义属性做主题令牌，一键切换深浅色。
  • 图形：装饰元素由 CSS 渐变 / 内联 SVG 绘制，不加载任何图片文件。
  • 字体：只用系统自带字体栈（黑体系 + 宋体系 + 等宽系），因此无需 CDN。
