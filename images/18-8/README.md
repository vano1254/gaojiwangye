# 18-8 地图数据说明

## 文件

| 文件 | 说明 |
| --- | --- |
| `china-geo.js` | 中国省级行政区划边界，包装为 `window.wzy_china_geo`，供 ECharts `registerMap` 使用（约 569 KB） |

## 来源与合规

- 数据来源：阿里云 **DataV.GeoAtlas**（<https://datav.aliyun.com/portal/school/atlas/area_selector>）的
  `100000_full.json`（全国省级行政区划，adcode `100000`）。
- 该数据依据**国家基础地理信息中心**公开的标准地图编制，包含 34 个省级行政区
  （含台湾省、香港特别行政区、澳门特别行政区）以及南海诸岛（adcode `100000_JD`，九段线范围）。
- 本页只做**课堂数据可视化演示**，不用于测绘、导航或任何出版用途；省界不作为权属依据。

## 为什么包装成 `.js`

页面需要双击直接打开（`file://` 协议）。浏览器在 `file://` 下会拦截 `fetch()` 读取本地 JSON，
因此把 GeoJSON 赋给全局变量 `window.wzy_china_geo`，用 `<script src>` 同步加载，断网也能显示。

## 坐标

GeoJSON 使用 WGS84 经纬度（与 ECharts 地图坐标系一致），城市节点直接写经纬度：

```js
{ name: '北京', value: [116.41, 39.90, 1280] }  // [经度, 纬度, 咨询量]
```

## 数据性质

地图上的省份咨询量、城市节点、飞线、KPI、趋势、排行、事件流**全部为教学模拟数据**，
按固定权重构造，与真实机构、真实业务无关。
