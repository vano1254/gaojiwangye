01 · 文本 → 数据
JSON.parse(wzy_text) 将 JSON 字符串变为 JavaScript 数据，之后就能读取属性、遍历数组。输入有语法错误时会抛出异常。

            
02 · 数据 → 文本
JSON.stringify(wzy_data, null, 2) 把数据转回 JSON 文本，第三个参数设置缩进；省略它就能得到紧凑文本。

            
03 · 六种数据类型
JSON 支持字符串、数字、布尔值、null、对象和数组。不支持函数、注释、undefined、单引号和末尾多余的逗号。
