王梓杨的 Lucide 图标（JS 运行时生成 SVG）

这一页只做一件事：一行 <script> 引入 cdn/lucide.min.js， 然后在页面里写 <i data-lucide="heart"></i>， JS 在运行时把这个 <i> 替换成一段内联 SVG。 所以刷新一下页面，<i> 就变成 <svg> 了 —— 现在页面上已经找不到那个 i 了。

一、一行 script + 一个 data-lucide 属性

<!-- 1. 引入 Lucide 的运行库（本地文件） -->
<script src="cdn/lucide.min.js"></script>

<!-- 2. 写一个带 data-lucide 的 i，名字就是图标名 -->
<i data-lucide="heart"></i>

<!-- 3. 让 Lucide 去把页面里所有 [data-lucide] 换掉 -->
<script>lucide.createIcons();</script>
关键区别：Font Awesome 是「CSS + 字体」，Lucide 是「JS + 图形」。 上一页的 <i class="fas fa-heart"> 永远不会变成别的东西； 这一页的 <i data-lucide="heart"> 在 3 行 JS 之后就没了，原地只剩一个 <svg>。

二、它偷偷把 i 换成了什么

按 F12 打开开发者工具，选中上面任意一个图标，看到的是这样一段：

<svg class="lucide lucide-heart" xmlns="http://www.w3.org/2000/svg"
     width="24" height="24" viewBox="0 0 24 24"
     fill="none" stroke="currentColor" stroke-width="2"
     stroke-linecap="round" stroke-linejoin="round">
  <path d="M19 14c1.49-1.46 3-3.21 3-5.5A5.5 5.5 0 0 0 16.5 3c-1.76 0-3 .5-4.5 2
           -1.5-1.5-2.74-2-4.5-2A5.5 5.5 0 0 0 2 8.5c0 2.3 1.5 4.05 3 5.5l7 7Z"/>
</svg>

三个信息量很大的属性：viewBox="0 0 24 24"（统一画在 24×24 的格子里）、 fill="none" stroke="currentColor"（只有描边、颜色跟着文字颜色）、 stroke-width="2"（线宽，可以直接改）。

四、变成内联 SVG 之后，CSS 能控制它每一根线

改颜色 color: #e74c3c
线更细 stroke-width: 1
线更粗 stroke-width: 3
改成实心 fill: #e74c3c
改尺寸 width/height: 56px
默认样式 stroke-width: 2

上面全是普通 CSS 改的：color 改色（因为 stroke="currentColor"）、 stroke-width 改线宽、fill 改实心、width/height 改尺寸。 用 <img> 引 SVG 文件是做不到这些的。

五、证据：图标是 JS「当场」造出来的

下面这个按钮每次点击会往框里插入一个 <i data-lucide="star">， 然后立刻调用一次 lucide.createIcons()。点一下试试： 

btn.onclick = function () {
    var i = document.createElement('i');
    i.setAttribute('data-lucide', 'star');   // 先插入一个空的 i
    drop.appendChild(i);
    lucide.createIcons();                    // 让 Lucide 把它换成 svg
};

六、和上一页（13-1）对比一下

对比项 13-1 Font Awesome（CSS + 字体） 13-2 Lucide（JS + SVG）
怎么引入 <link> 一个 CSS <script> 一个 JS
怎么写 <i class="fas fa-heart"> <i data-lucide="heart">
页面上最终是什么 还是一个 <i>，图标在 ::before 里 被换成一段 <svg><path>
没有 JS 会怎样 照常显示（图标是 CSS + 字体） 一个都不显示（SVG 是 JS 造的）
改线宽 只能换字重（400 / 900），没别的档 stroke-width 想写几就写几
文件体积 整套字体 1 MB 左右，用不用都这么大 JS 约 444 KB，图标按需调用
适合场景 图标多、要统一风格、不想要 JS 要精细控制线条、要和页面视觉一起调
