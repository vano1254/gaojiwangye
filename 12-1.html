王梓杨的 Font Awesome 字体图标

Font Awesome Free 6.7.2，样式表和字体文件都已下载到本目录 cdn/ 下，断网也能正常显示。 这里的图标不是图片，是字体：一个 <i> 标签加两个类名就是一个图标， 放大不糊、改字号不糊、颜色跟着文字颜色走。

一、基本用法：一个 i 标签就是一个图标

<link rel="stylesheet" href="cdn/all.min.css">

<i class="fa-solid fa-house"></i>    <!-- 实心房子 -->
<i class="fa-regular fa-star"></i>   <!-- 线框星星 -->
<i class="fa-brands fa-github"></i> <!-- GitHub 标志 -->

类名分两段：fa-solid / fa-regular / fa-brands 决定用哪套字体，fa-图标名 决定用哪个字形。

五、字体图标的好处（这些都是图片做不到的）

1. 字号一改，图标就跟着变大变小

<i class="fa-solid fa-house fa-1x"></i>
<i class="fa-solid fa-house fa-2x"></i>   <!-- .fa-2x 就是 font-size: 2em -->
<i class="fa-solid fa-house fa-5x"></i>

2. 文字颜色一改，图标颜色就跟着变（当前色 currentColor）

<i class="fa-solid fa-heart" style="color:#e74c3c"></i>

3. 直接转方向、加旋转动画

<i class="fa-solid fa-arrow-right fa-rotate-90"></i>   <!-- 转 90° -->
<i class="fa-solid fa-gear fa-spin"></i>            <!-- 一直转（纯 CSS animation）-->
<i class="fa-solid fa-heart fa-beat"></i>           <!-- 心跳 -->
<i class="fa-solid fa-house fa-bounce"></i>         <!-- 弹跳 -->

4. 两个图标堆叠成一个（fa-stack）

<span class="fa-stack fa-2x">
    <i class="fa-solid fa-circle fa-stack-2x"></i>   <!-- 底层：大图标 -->
    <i class="fa-solid fa-check  fa-stack-1x"></i>   <!-- 上层：小图标 -->
</span>

5. 当成列表项目符号（fa-ul + fa-li）

  • 图标是字体，放大缩小都很清晰
  • 颜色直接用 color 控制，不用再准备一套配色图片
  • 列表的缩进、换行由浏览器自动处理，不会像图片那样对不齐

六、它到底是怎么把一个字变成图标的

原理就四步：准备一套字体 → 把图标画在字体的「私用区」码位上 → 用 @font-face 加载 → 用伪元素把那个字打出来。 所以图标本质上就是一个字，只不过这个字长得像图标。 

/* 1. 用 @font-face 把字体文件当字体加载（文件就在 cdn/webfonts/ 里）*/
@font-face {
    font-family: "Font Awesome 6 Free";
    font-weight: 900;
    src: url("../webfonts/fa-solid-900.woff2") format("woff2");
}

/* 2. 给 .fa-solid 指定用这套字体 */
.fa { font-family: var(--fa-style-family, "Font Awesome 6 Free"); font-weight: var(--fa-style, 900); }

/* 3. 每个图标类只负责记下自己在私用区的编码，比如房子的码位是 F015（十进制 61461）*/
.fa-house { --fa: "\f015"; }

/* 4. 一条总规则把编码打出来 —— 藏在伪元素里，所以 HTML 里只写空标签就够了 */
.fa-solid:before, .fa-regular:before, .fa-brands:before, .fa:before { content: var(--fa); }

几个已经查到的真实码位：房子 fa-house = \f015， 齿轮 fa-gear = \f013，星星 fa-star = \f005， 心动 fa-heart = \f004，GitHub fa-github = \f09b。 这些码位都在 Unicode 私用区（U+E000–U+F8FF）里，正常输入法打不出来，只给图标字体自己用。

也正因为是「字」，所以：能选中的是一段文字、能被屏幕阅读器读到（所以要配 aria-hidden="true" 或文字说明）、 字体文件只要几十 KB 就能装下几百个图标，比几百张 PNG 小得多。
