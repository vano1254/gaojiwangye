要点说明

1. * { box-sizing: border-box }：盒子的宽度按 100% / 50% / 33.33% / 25% 来分，内边距算在宽度里，所以留间距不用写 calc()。
2. .box { float: left } 浮动排列，容器用 ::after { clear: both } 清除浮动；媒体查询里只改 .box 的 width，一行就从 1 个变成 2 个、3 个、4 个。
3. min-width: 480px 的意思是「视口宽度 ≥ 480px 时才生效」，三条查询从小往大写，后面的自动覆盖前面的。
4. body { min-width: 320px }：视口再窄页面也不会小于 320px，出现横向滚动条，而不是把盒子挤变形。
5. 拓展——三个媒体类型：@media screen 管屏幕上怎么显示（彩色卡片 + 阴影 + 悬停，断点写成 screen and (min-width: 480px)）；@media print 管打印，改成白底黑框、去掉阴影和彩色底、一行固定 4 个，省墨又看得清；@media speech 管语音朗读，去掉提示条、页脚这些装饰，只留正文。
6. 页面全部是原生 HTML + CSS，没有 JavaScript，也没有引用任何外部库。
