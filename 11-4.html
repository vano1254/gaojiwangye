上一页 11-2 演示的是动画「效果」，这一页专门比较动画「节奏」。

鼠标移到某一行可以只暂停那一行，方便逐条对比；勾选下面的开关则全部一起停。

动画时长统一 1.8s，往复播放（alternate）

同一段动画 · 七种节奏

linear · 匀速linear
ease · 默认ease
ease-in · 慢起快收ease-in
ease-out · 快起慢收ease-out
ease-in-out · 两头慢ease-in-out
回弹 · 冲过头再回来cubic-bezier(.34, 1.56, .64, 1)
阶梯 · 逐格跳steps(6, end)

要点说明

  1. animation-timing-function 决定动画在每一段里怎么加速、怎么减速。关键帧一模一样，节奏可以完全不同 —— 上面七行就是证明。
  2. linear 匀速；ease 是默认值，起步稍快、结尾变慢；ease-in 慢起快收；ease-out 快起慢收；ease-in-out 两头慢、中间快。
  3. cubic-bezier(x1, y1, x2, y2) 自定义曲线，四个数就是两个控制点。y 值可以超过 1，就会「冲过头再回来」，做出回弹感（第 6 行）。
  4. steps(n, end) 不做平滑补间，把整段切成 n 格跳着走 —— 第 7 行的点是一格一格挪过去的。
  5. 本页为了让点来回走，动画改的是 left，会触发布局重排。实际项目里更推荐动 transform: translateX()，只触发合成，性能更好。
  6. 「暂停全部」用的是 :has(#pause:checked) —— 不写一行 JavaScript 也能让勾选框控制整页动画。
  7. 系统开启「减少动态效果」时，动画会自动停用，点停回起点。
  8. 整页纯原生 HTML + CSS，没有 JavaScript，也没有引用任何外部库，可离线打开。

/* 七行共用同一段关键帧 */
@keyframes slide {
    from { left: 2px; }
    to   { left: 72%; }
}

/* 点的公共样式：时长、往复都一样 */
.dot {
    position: absolute;
    left: 2px;
    width: 16px;
    height: 16px;
    border-radius: 50%;
    animation: slide 1.8s infinite alternate;
}

/* 唯一不同的是时间函数 */
.tf-linear .dot { animation-timing-function: linear; }
.tf-ease   .dot { animation-timing-function: ease; }
.tf-in     .dot { animation-timing-function: ease-in; }
.tf-out    .dot { animation-timing-function: ease-out; }
.tf-inout  .dot { animation-timing-function: ease-in-out; }
.tf-back   .dot { animation-timing-function: cubic-bezier(.34, 1.56, .64, 1); }
.tf-steps  .dot { animation-timing-function: steps(6, end); }

/* 悬停单行暂停：animation-play-state 不继承，要写在动的元素上 */
.row:hover .dot { animation-play-state: paused; }

/* 纯 CSS 全局暂停 */
.page:has(#pause:checked) .dot { animation-play-state: paused; }
