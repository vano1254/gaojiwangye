二、内联 SVG：把 svg 直接写进页面（可以随便改）

把 svg 代码粘进 HTML，它就变成了 DOM 的一部分，于是颜色（color / fill / stroke）、 线条粗细（stroke-width）、尺寸、旋转全都能用 CSS 控制。

house 默认 24×24 网格，stroke-width 2
search 颜色改 color（描边是 currentColor）
sun 尺寸改 width/height，矢量不糊
heart 改成实心：fill:currentColor
star 细线：stroke-width 1
bell 粗线：stroke-width 3
settings 旋转：transform rotate(45deg)
moon 深色也能直接用

三、Lucide 图标的三个特点

1. 统一画在 24×24 的网格上 —— 每个文件都是 viewBox="0 0 24 24"，所以几十个图标放在一起，粗细、大小、视觉重量都是一致的。

2. 是「线性图标」不是「实心图标」 —— 用 stroke 描边画出来，fill="none"。想变实心，改一个 fill: currentColor 就行。

3. 描边默认用当前文字颜色 —— 文件里写的是 stroke="currentColor"，所以在内联用法下，父元素的 color 是什么颜色，图标就是什么颜色。

四、字体图标（Font Awesome）和 SVG 图标（Lucide）怎么选

对比项 字体图标 · Font Awesome SVG 图标 · Lucide
文件形式 1 个 css + 4 个字体文件（woff2/ttf），一套字体装 2000 多个图标 每个图标一个独立的 .svg 文本文件，用哪个下哪个
页面里怎么写 <i class="fa-solid fa-house"></i> <img src="house.svg"> 或内联 <svg>...</svg>
改颜色 color 一改就变（字就是图标） 内联可以随便改；用 <img> 引的改不了
改线条粗细 只能换字重：fa-regular(400) / fa-solid(900)，没有更细的 stroke-width 想写几写几，1 / 2 / 3 都能试
放大后清晰度 字体也是矢量，放多大都不糊 矢量图形，放多大都不糊
体积 整套字体约 1 MB（全量），不管用几个都这么大 单个图标 0.4~1 KB，用多少下多少
能不能做复杂动画 只能整体转/缩放/变色（CSS animation 作用在一个字上） 可以精确控制每一根线条（stroke-dasharray 画线动画等）
主要缺点 只能单色；要靠伪元素 :before 显示；改不了内部结构 图标一多要管理很多小文件；<img> 方式不能改样式

一句话总结：图标少、样式统一、图省事 → 字体图标； 图标要改颜色改粗细、要按需加载、要做精细动画 → SVG 图标。
