三个关键属性，搭起一个 3D 场景

① 透视 · perspective

写在观察容器上，决定视点与平面的距离。本页使用 700px；数值越小，透视通常越强。

② 空间 · preserve-3d

写在承载多个面的父容器上，保留子元素的三维位置。它不继承，多层结构需要逐层设置。

③ 运动 · transform

使用 rotateX / Y / Z 和 translateZ，把平面旋转或移动到空间中，再通过关键帧让它运动。

查看立方体的核心 CSS（含中文注释） 
/* 观察距离：放在立方体的父容器 */
.scene { perspective: 700px; }

/* 六个面保持三维关系，旋转时作为一个整体 */
.cube {
    width: 100px;
    height: 100px;
    position: relative;
    transform-style: preserve-3d;
    animation: cube-spin 10s linear infinite;
}

/* 每个面先转向，再沿自己的 Z 轴平移 50px */
.front { transform: translateZ(50px); }
.right { transform: rotateY(90deg) translateZ(50px); }
.top   { transform: rotateX(90deg) translateZ(50px); }

@keyframes cube-spin {
    from { transform: rotateX(-20deg) rotateY(-30deg); }
    to   { transform: rotateX(340deg) rotateY(330deg); }
}

/* 暂停属性要写在真正承载动画的元素上 */
.demo:hover .anim { animation-play-state: paused; }

注意：变换顺序会影响结果；在需要保留三维关系的容器上使用某些分组属性（例如 opacity 小于 1 或 overflow: hidden），可能把内部的立体结构压平。尊重系统减少动态效果设置，避免强制播放。
