JavaScript 的三种控制结构

顺序、条件、循环 —— 再长的脚本，拆开看也只是这三种结构在排列和嵌套。

  • 顺序从上到下一句一句走
  • 条件真假不同走不同的路
  • 循环条件成立就重复做

1顺序结构

没有分支、没有跳转的时候，引擎就从上到下一句一句执行，每句只执行一次。 下面五行代码的编号就是执行顺序：第 ③ 句用到第 ①② 句算好的值，第 ④ 句再用 ③ 的结果， 最后第 ⑤ 句把结果输出。这就是顺序结构 —— 不回头、不跳步。

var wzy_price = 12; // 单价 12 元 var wzy_count = 4; // 数量 4 件 var wzy_total = wzy_price * wzy_count; // 小计 48 元 var wzy_pay = wzy_total - 8; // 用 8 元优惠券 → 40 console.log(wzy_pay); // 输出 40

点击下面的「逐步执行」，右边的日志会一行一行往下写。

每 0.6 秒走一句，注意它从来不会倒回去。

2条件结构

条件让代码分岔：条件为真走一条路，为假走另一条。常见的两种写法是 if / else if / else（按顺序往下问，问到一个「是」就停）和 switch（按值直接分派，靠 break 跳出）。

if / else if / else —— 多条路里选一条

if (wzy_s >= 90) { // 90 及以上 → 优秀 } else if (wzy_s >= 80) { // 80~89 → 良好 } else if (wzy_s >= 60) { // 60~79 → 及格 } else { // 60 以下 → 不及格 }

输入一个分数，点「判断等级」。

问到一个「是」就停，后面的 else if 根本不会执行。

switch —— 按值分派，靠 break 跳出

switch (wzy_d) { case 1: case 2: case 3: case 4: case 5: wzy_name = "工作日"; break; // 五个 case 共用 case 6: case 7: wzy_name = "周末"; break; default: wzy_name = "无效的星期"; }

选一个数字，点「查星期」。

去掉 break 就会「穿」到下一个 case，这叫 fallthrough。

只判断「行 / 不行」的时候，还可以用三元运算符写成一行： var wzy_tip = wzy_s >= 60 ? "及格" : "不及格";

3循环结构

循环让代码重复：条件成立就一直做，条件不成立就退出。 三种常见写法 —— for（次数已知）、while（先判断再进）、 do…while（先做一次再判断）；循环里面还能再套循环。

for —— 按次数重复：累加 1 ~ n

for (i = 1; i <= n; i++) 会实实在在跑 n 次。

点「累加 1 ~ n」，看循环一轮一轮往下推。

while —— 先判断，再进循环：倒计时

条件 wzy_n > 0 一旦不成立，循环立刻结束。

点按钮，从 5 数到 1。

嵌套循环 —— 九九乘法表

外层 9 行、内层 1~i 列，j <= i 才形成一个三角形。

4合起来用：找质数

实际写代码时三种结构是叠在一起的：外层 for 逐个试数（循环）， 内层 for 做除法（循环套循环），if 一发现能整除就 break 提前结束内层（条件），最后再按结果收集。

内层只试到 d * d <= n，超出就没必要再试。

点「找出 1 ~ n 的质数」。

✓三种结构小结

结构 关键字 怎么走 本页演示
顺序 没有关键字（就是默认） 自上而下，一句一句，每句执行一次 ① 购物小计：①→⑤ 依次执行，不回头
条件 if / else if / else / switch / ? : 按条件的真假，只走其中一条路 ② 分数等级、星期查询
循环 for / while / do…while 条件成立就重复，直到条件不成立 ③ 累加 1~n、倒计时、九九乘法表
组合 循环里套条件、循环里套循环 外层遍历、内层筛选，命中就 break ④ 找质数

记住一句话：顺序是默认，条件负责选，循环负责重复；三者按需要嵌套，就是一段完整的程序逻辑。
