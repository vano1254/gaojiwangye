用 @keyframes 定义关键帧、animation 调用动画，做出的九个纯 CSS 动画效果。

鼠标移到任意卡片上可以暂停该卡片的动画，方便慢慢看；系统开启「减少动态效果」时全部动画会自动停用。

要点说明

  1. @keyframes 负责定义关键帧，animation 一次性给出「动画名 时长 速度曲线 延迟 循环次数 方向」这几个参数，两者配合才动起来。
  2. animation-play-state: paused 可以暂停 / 继续动画；这个属性不会继承，必须写在真正带 animation 的那个元素上（所以本页给每个动的元素都加了 .anim 类）。
  3. animation-delay 用来把同一个动画错开时间播放，第 ⑥ 个「三点波浪」就是同一个关键帧 + 三个不同延迟做出来的。
  4. steps() 让动画逐格跳变、不做补间，第 ⑧ 个「打字机」用 steps(20, end) 让宽度一格一格长出来，光标再用另一个动画闪。
  5. transform 的 translate / scale / rotate / rotateY 是动画的主力；rotateY 这类 3D 变换要给父级加 perspective 才有立体感。
  6. 动画优先动 transform 和 opacity：它们只触发合成，不重新排版，性能最好；动 width / height 会触发布局，尽量少用（第 ⑦ ⑧ 个是为了演示效果才动的宽度）。
  7. 用 @media (prefers-reduced-motion: reduce) 在用户开启「减少动态效果」时停掉动画，照顾对动效敏感的人。
  8. 整页是纯原生 HTML + CSS，没有 JavaScript，也没有引用任何外部库，断网也能正常播放。
