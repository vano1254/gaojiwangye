GET 与 POST

GET 常用于读取数据；POST 常用于提交数据。本页的 POST 示例请求 /posts，使用 JSON.stringify() 将对象转为请求体。

HTTP 错误也有响应

404、500 等状态仍可能返回正文。本页保留这些数据并标记失败，不会只显示一个笼统的报错。HEAD 请求正常情况下没有响应正文。

网络失败与超时

断网、跨域限制或连接异常时，浏览器可能无法提供 HTTP 状态。超时和手动取消由 AbortController 处理；修改参数后可再次发送。
