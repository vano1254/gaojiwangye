王梓杨的数组演示

点按钮，在真实数组上跑方法；下面会记下返回值，以及原数组有没有被改。

橙色按钮会改动原数组，绿色按钮不会。想回到初始状态就点「重置」。

操作台

① 会改原数组（mutating）

② 查找与判断（不改原数组）

③ 生成新数组 / 新值（不改原数组）

一、哪些会改原数组，哪些不会

这是数组最容易出错的地方：改原数组的方法返回的不是新数组， 而是长度、被删掉的元素或者原数组本身；不改的方法一定返回新值，原数组纹丝不动。

会改原数组（7 个） 返回值 不改原数组（15 个） 返回值
push() 末尾加 新长度 indexOf() / findIndex() 下标（找不到 -1）
pop() 末尾删 被删的元素 includes() / some() / every() true / false
unshift() 开头加 新长度 find() / at() 找到的元素
shift() 开头删 被删的元素 slice() / concat() / flat() 新数组
splice() 任意位置删 / 插 被删元素组成的新数组 map() / filter() 新数组
sort() 排序 原数组本身（已排好） reduce() 累加出来的单个值
reverse() 反转 原数组本身（已反转） join() / Array.isArray() 字符串 / 布尔值

记忆口诀：push / pop / shift / unshift / splice / sort / reverse 这七个是「动手派」， 其余都是「看一眼就走」。

二、创建数组的五种写法

// 1. 字面量：最常用，方括号里直接写元素
var wzy_a = [1, 2, 3];

// 2. 构造函数：只有一个数字参数时是「长度」，不是元素
var wzy_b = new Array(3);          // [空 × 3]，长度 3，不是 [3]
var wzy_c = new Array(1, 2, 3);    // [1, 2, 3]

// 3. Array.of()：解决上面那个坑，一个数字就是一个元素
var wzy_d = Array.of(3);           // [3]

// 4. Array.from()：把类数组 / 可迭代对象变成真数组
var wzy_e = Array.from("abc");                  // ["a", "b", "c"]
var wzy_f = Array.from({ length: 5 }, function (_, i) { return i * 2; });  // [0,2,4,6,8]

// 5. 展开运算符：复制一个数组（浅拷贝）
var wzy_g = [...wzy_a];            // [1, 2, 3]，改 wzy_g 不影响 wzy_a

new Array(3) 得到的是长度 3 的空数组，这个坑几乎每个人都踩过，所以有了 Array.of()。

三、链式调用：一行算完「偶数翻倍再求和」

不改原数组的方法都返回新值，所以可以一个接一个往下接 —— 这叫链式调用。 

var wzy_scores = [72, 85, 91, 64, 88, 95];

var wzy_total = wzy_scores
    .filter(function (n) { return n >= 80; })   // 先筛出及格的：[85, 91, 88, 95]
    .map(function (n) { return n - 80; })       // 再每人减 80：[5, 11, 8, 15]
    .reduce(function (a, b) { return a + b; }, 0);  // 最后求和：39

console.log(wzy_total);        // 39
console.log(wzy_scores);       // [72, 85, 91, 64, 88, 95] —— 原数组没变

注意 reduce 的第二个参数 0 是初始值，不给它的话，空数组会直接报错。

四、要点说明

  1. 数组下标从 0 开始，最后一个元素是 arr[arr.length - 1]，或者更省事的 arr.at(-1)。
  2. sort() 默认按字符串比较，所以 [10, 9, 2].sort() 会得到 [10, 2, 9]。排数字必须给比较函数 (a, b) => a - b。
  3. splice() 会改原数组，slice() 不会 —— 只差一个字母，行为完全相反。
  4. find() 找第一个满足条件的元素，filter() 找所有满足条件的元素。
  5. forEach() 没有返回值（永远是 undefined），想拿结果要用 map()。
  6. map() 返回的数组长度一定和原数组一样，filter() 可能变短。
  7. 展开运算符 [...arr] 和 slice() 都是浅拷贝：元素是对象时，复制的是引用。
  8. 本页 22 个方法全部在真实数组上跑，日志里会标出「改了原数组」还是「没改」，多试点几次就有感觉了。
